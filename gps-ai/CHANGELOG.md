# Changelog
## 0.2.0 — 2026-10-12
- App desktop (Electron) com tela simples: clima, comandos digitados, rota (OSRM demo) e simulação de viagem com voz pt-BR.
- Instalador Windows (NSIS) gerado pelo GitHub Actions; scripts RODAR.bat e GERAR-INSTALADOR.bat.

## 0.1.0 — 2026-10-11
- Núcleo TypeScript: roteamento (cliente OSRM), sessão de navegação com detecção de desvio, anúncios de voz pt-BR sem repetição, cliente Open-Meteo, parser de intenções pt-BR, preferências com exclusão (LGPD).
- 24 testes unitários com serviços externos simulados.
